# Use Cases

Этот файл нужен для ручной проверки skill после изменений. Проверяй не красоту текста, а поведение: правильный маршрут, локальные файлы, handoff и отсутствие выдуманных фактов.

## Pass Criteria

Skill проходит проверку, если:

- отвечает на русском, на "ты", спокойно и по делу
- в пустой папке сначала создаёт файлы, потом задаёт вопросы
- не ждёт slash-команды и маршрутизирует по обычной речи
- сохраняет значимые знания локально
- помечает неизвестное как `[уточнить]` или `[гипотеза]`
- после шага показывает созданные/изменённые файлы и один следующий шаг
- обновляет `база/индекс.md`, `база/открытые-вопросы.md`, `база/паттерны.md`, `агенты/README.md` после значимых изменений

## UC-001 Empty Folder Bootstrap

**Setup:** пустая рабочая папка.

**Prompt:**

```text
Используй $ekipazh. Я консультант по продажам для небольших B2B-команд. Настрой папку под мой бизнес.
```

**Expected route:** `SKILL.md` -> `references/onboarding.md` -> `scripts/bootstrap_workspace.py`.

**Expected artifacts:**

- `профиль/бизнес.md`
- `профиль/стиль.md`
- `профиль/состояние.md`
- `решения/решение-001-тон.md`
- `база/индекс.md`
- `база/открытые-вопросы.md`
- `база/факты.md`
- `база/термины.md`
- `база/паттерны.md`
- `агенты/README.md`

**Expected behavior:**

- вносит известные факты: консультант по продажам, B2B-команды
- остальные поля помечает `[уточнить]`
- задаёт 2-3 вопроса, не длинную анкету
- показывает `[Неопределённость: 0.XX]`

## UC-002 Status In Existing Workspace

**Setup:** папка после UC-001.

**Prompt:**

```text
Что у нас уже готово и что делать дальше?
```

**Expected route:** `references/workspace.md` + `references/operating-loop.md`.

**Expected behavior:**

- сканирует профиль, анализ, правила, контент, базу, агентов
- показывает компактный статус
- не предлагает общий бизнес-консалтинг
- предлагает один лучший следующий шаг

## UC-003 Analysis

**Setup:** есть `профиль/бизнес.md`.

**Prompt:**

```text
Кто мои клиенты и конкуренты? Давай разберём рынок.
```

**Expected route:** `references/analysis.md`.

**Expected artifacts:**

- `анализ/рынок.md`
- `анализ/конкуренты.md`
- `анализ/swot.md`
- `анализ/персоны/персона-*.md`
- `анализ/персоны/анти-персона.md`

**Expected behavior:**

- если web access недоступен, рыночные выводы помечает `[гипотеза]`
- не повторяет вопросы, ответы на которые уже есть в профиле
- обновляет `база/факты.md`, `база/паттерны.md`, `база/открытые-вопросы.md`

## UC-004 Rule Capture

**Prompt:**

```text
Запомни: я никогда не пишу "индивидуальный подход" и не обещаю быстрый рост продаж.
```

**Expected route:** `references/rules.md`.

**Expected artifacts:**

- `правила/правило-NNN-*.md`
- обновлённые `база/термины.md` или `база/паттерны.md`

**Expected behavior:**

- формулирует правило с trigger, do, don't, good result
- применяет правило к будущим постам, КП и возражениям

## UC-005 Post Generation And Inline Edit

**Prompt:**

```text
Напиши пост про то, почему отдел продаж буксует без нормального разбора звонков.
```

**Expected route:** `references/content.md`.

**Expected behavior:**

- читает профиль, стиль, правила, последние посты
- создаёт 3 варианта: экспертный, личный, продающий
- проверяет повтор темы

**Follow-up prompt:**

```text
Вариант 2, но короче и без пафоса.
```

**Expected behavior:**

- правит выбранный вариант, не запускает новый процесс
- если пользователь подтверждает, сохраняет в `контент/посты/черновики/`

## UC-006 Proposal

**Prompt:**

```text
Сделай КП для компании Альфа. Им надо навести порядок в воронке и научить менеджеров разбирать звонки.
```

**Expected route:** `references/sales.md`.

**Expected artifacts:**

- `контент/кп/черновики/кп-*.md`

**Expected behavior:**

- уточняет бюджет, сроки и обращение, если неизвестны
- не выдумывает цены
- даёт два тарифа
- после КП предлагает PDF как следующий шаг

## UC-007 Objection

**Prompt:**

```text
Клиент сказал: "У нас сейчас нет бюджета, давайте потом". Как ответить?
```

**Expected route:** `references/sales.md`.

**Expected artifacts:**

- `контент/возражения/*.md`

**Expected behavior:**

- определяет тип возражения
- даёт разбор и 2 варианта ответа
- если возражение повторяется, предлагает правило

## UC-008 Format

**Setup:** есть черновик КП.

**Prompt:**

```text
Оформи это КП как PDF для клиента.
```

**Expected route:** `references/format.md`.

**Expected behavior:**

- выбирает целевой Markdown-артефакт или уточняет один вопрос
- если Typst доступен, создаёт `.typ` и `.pdf`
- если Typst недоступен, создаёт `.typ` или объясняет, как скомпилировать позже
- не переписывает смысл КП

## UC-009 Agent Factory

**Prompt:**

```text
Я каждую неделю пишу посты в Telegram по одному процессу. Сделай агента под это.
```

**Expected route:** `references/agents.md`.

**Expected artifacts:**

- `агенты/агент-*.md`
- если процесс зрелый или пользователь подтвердил: `.agents/skills/<name>/SKILL.md`
- обновлённый `агенты/README.md`

**Expected behavior:**

- сначала создаёт role spec, если процесс ещё не проверен
- не дублирует существующего агента
- предлагает тест на реальном примере

## UC-010 Validation

**Prompt:**

```text
Проверь, всё ли сходится в базе и можно ли уже использовать это для контента и КП.
```

**Expected route:** `references/validation.md`.

**Expected artifacts:**

- `база/validation-report.md`

**Expected behavior:**

- выдаёт verdict: `GO`, `NEEDS WORK` или `CRITICAL`
- показывает findings с severity и action
- не называет неполную базу готовой

## Negative Use Cases

Эти запросы не должны триггерить Ekipazh:

- “Исправь TypeScript ошибку в React-компоненте.”
- “Сколько сейчас времени?”
- “Сконвертируй JSON в YAML.”
- “Сделай SQL-запрос к базе.”

Если skill всё же активирован явно, он должен коротко сказать, что это не бизнес-операторская задача, и выполнить обычную задачу без создания бизнес-артефактов.
