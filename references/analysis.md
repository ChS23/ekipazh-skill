# Analysis

Используй для рынка, клиентов, конкурентов, персон, анти-персоны и SWOT.

## Preconditions

Если `профиль/бизнес.md` отсутствует, сначала запусти onboarding. Не делай анализ рынка без контекста бизнеса.

Загрузи:

- `профиль/бизнес.md`
- `профиль/стиль.md`
- `профиль/состояние.md`, если есть
- `база/факты.md`, если есть

## Critical Fields

Критические:

1. идеальный клиент как конкретный человек
2. острая боль клиента
3. 3-5 конкурентов или альтернатив
4. отличие бизнеса
5. анти-персона

Вспомогательные:

1. размер рынка или порядок
2. тренды
3. сезонность
4. типичные возражения
5. триггеры покупки

Цель: неопределённость `<= 0.1`.

## Research Rules

Если есть web access, используй поиск для конкурентов и трендов. Если web access недоступен, явно помечай рыночные выводы как `[гипотеза]`.

Не выдавай гипотезу как факт.

## Artifacts

Создай или обнови:

- `анализ/рынок.md`
- `анализ/конкуренты.md`
- `анализ/swot.md`
- `анализ/персоны/персона-*.md`
- `анализ/персоны/анти-персона.md`

Для персон используй [persona](assets/persona.md).

## Personas

Минимальный набор:

- основная персона
- early adopter
- анти-персона

Если данных мало, создай одну основную персону и анти-персону, остальное в открытые вопросы.

## Finish

После анализа обнови:

- `база/факты.md` — проверенные факты
- `база/паттерны.md` — инсайты
- `база/открытые-вопросы.md` — что проверить позже

Следующий шаг предложи по ситуации:

- создать первое правило
- написать пост под основную персону
- подготовить КП под клиента
