# Workspace

Экипаж строит локальную базу бизнеса в текущей рабочей папке. Всё должно быть переносимым Markdown, пригодным для git и для будущих агентов.

## Canonical Structure

```text
профиль/
  бизнес.md
  стиль.md
  состояние.md

анализ/
  рынок.md
  конкуренты.md
  swot.md
  персоны/

правила/
  правило-NNN-*.md

контент/
  посты/
    идеи/
    черновики/
    опубликовано/
  кп/
    черновики/
    отправлено/
    принято/
    отказано/
  возражения/

решения/
  решение-NNN-*.md

база/
  индекс.md
  факты.md
  термины.md
  открытые-вопросы.md
  паттерны.md

агенты/
  README.md
  агент-*.md

.agents/
  skills/
    <workflow-name>/
      SKILL.md
```

## Status Signals

- `профиль/бизнес.md` отсутствует: проект не настроен.
- профиль есть, но анализа нет: можно работать, но рынок и персоны пока гипотезы.
- нет правил: генерация возможна, но стиль будет менее точным.
- есть 5+ исправлений одного типа: пора оформить правило.
- есть повторяемый процесс: пора создать локального агента или мини-скилл.

## File Rules

- Все новые файлы должны иметь понятные имена.
- Для контента используй `YYYY-MM-DD-краткая-тема.md`, если нет лучшего имени.
- Для правил используй следующий свободный номер: `правило-001-*.md`.
- Для решений используй следующий свободный номер: `решение-001-*.md`.
- Не удаляй пользовательские файлы без явной просьбы.

## Knowledge Base

`база/индекс.md` — карта того, что известно и где лежит.

`база/факты.md` — проверенные факты о бизнесе, клиентах, продуктах.

`база/термины.md` — словарь терминов бизнеса и формулировки, которые пользователь любит/не любит.

`база/открытые-вопросы.md` — всё, что осталось неясным.

`база/паттерны.md` — повторяющиеся наблюдения: правки, темы, каналы, реакции клиентов.

Обновляй базу после значимых разговоров. Не превращай её в лог чата; сохраняй только знания, которые помогут будущим агентам.

## Status Output

Когда пользователь спрашивает статус, дай компактный вывод:

```text
Экипаж — [название бизнеса или "папка не настроена"]

Профиль: [готов / черновик / нет]
Анализ: [N персон, конкуренты да/нет, SWOT да/нет]
Правила: [N]
Контент: [N постов, N КП, N возражений]
База: [факты/термины/открытые вопросы]
Агенты: [N локальных ролей, N мини-скиллов]

Лучший следующий шаг: ...
```
