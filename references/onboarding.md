# Onboarding

Используй этот процесс, когда папка пустая, нет `профиль/бизнес.md`, пользователь рассказывает о себе или просит “настроить под меня”.

## Goal

Создать первичную рабочую базу:

- `профиль/бизнес.md`
- `профиль/стиль.md`
- `профиль/состояние.md`
- `решения/решение-001-тон.md`
- `база/индекс.md`
- `база/открытые-вопросы.md`

## Critical Fields

Критические поля:

1. продукт/услуга
2. типичный клиент
3. ценность для клиента
4. тон общения
5. миссия или зачем бизнес существует
6. главная боль в текущей работе
7. что уже работает

Вспомогательные поля:

1. каналы продаж
2. средний чек
3. команда
4. запретные темы
5. примеры хорошего контента
6. примеры плохого контента
7. опыт с ИИ

Цель: неопределённость `<= 0.1`.

## First Message In Empty Folder

Если пользователь ещё не дал контекст, скажи коротко:

```text
Папка пустая. Я заведу базу бизнеса и буду наполнять её по ходу разговора.

Начнём с трёх вещей:
1. Что ты делаешь и для кого?
2. Какой результат клиент получает после работы с тобой?
3. Что сейчас больше всего забирает время или раздражает?
```

Если пользователь уже дал ввод, не повторяй вступление. Извлеки факты и задай только недостающие вопросы.

## Interview Rules

- Задавай максимум 3 вопроса за раз.
- Не спрашивай то, что уже известно из файлов или сообщения.
- Если пользователь не знает, предложи варианты.
- Не используй бизнес-жаргон.
- Не обещай “стратегию”; строишь рабочую базу.

## Drafting

Когда информации достаточно или пользователь просит не спрашивать дальше:

1. Создай папки из [workspace](references/workspace.md).
2. Заполни assets:
   - [business](assets/business.md)
   - [style](assets/style.md)
   - [current-state](assets/current-state.md)
   - [decision](assets/decision.md)
3. Все неизвестные поля пометь `[уточнить]`.
4. В `база/открытые-вопросы.md` вынеси вопросы, которые блокируют качество.

## First Decision

Создай `решения/решение-001-тон.md`:

- контекст: первичная настройка Экипажа
- решение: выбранный тон и обращение
- альтернативы: более формально / более дружески / экспертно
- метрика успеха: пользователь меньше правит стиль

## Finish Message

После сохранения:

```text
База заведена:
- профиль/бизнес.md
- профиль/стиль.md
- профиль/состояние.md
- решения/решение-001-тон.md
- база/индекс.md

Лучший следующий шаг: [анализ аудитории / первый пост / первое правило]
```
