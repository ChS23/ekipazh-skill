# Format

Используй для оформления Markdown-артефактов в PDF или Typst-документы.

## When To Use

- пользователь говорит “сделай PDF”, “оформи красиво”, “для клиента”, “распечатать”, “отправить”
- после КП предложи PDF как следующий шаг, если документ пойдёт клиенту
- для постов и возражений обычно PDF не нужен; скажи коротко, что это текст для канала, и предложи сохранить Markdown

## Load Context

Прочитай:

- целевой Markdown-артефакт
- `профиль/бизнес.md`
- `профиль/стиль.md`
- применимые `правила/*.md`
- визуальные предпочтения из `база/термины.md` или `решения/*.md`, если есть

## Select Artifact

Если путь не указан:

1. Найди последние файлы в `контент/**/*.md`, `анализ/*.md`, `профиль/*.md`.
2. Выбери самый вероятный по запросу.
3. Если кандидатов несколько, задай один уточняющий вопрос.

## Output Rules

Для КП:

- деловой, чистый документ
- шапка, понимание задачи, решение, тарифы, почему мы, следующий шаг, контакты
- тарифы оставь таблицей
- цены не выдумывай

Для анализа или профиля:

- отчётная структура
- таблицы для SWOT, конкурентов, тарифов
- персоны можно вынести отдельными секциями

Для поста:

- PDF не создавать без явной причины
- предложить оставить в `контент/посты/черновики/` или скопировать в канал

## Typst Flow

Если есть возможность выполнять shell-команды и установлен `typst`:

1. Создай `.typ` рядом с исходным `.md`.
2. Скомпилируй:

```bash
typst compile artifact.typ artifact.pdf
```

3. Покажи путь к `.pdf`.

Если `typst` недоступен:

- создай `.typ` рядом с исходным файлом, если filesystem tools доступны
- скажи, что PDF можно скомпилировать позже через Typst
- не превращай отсутствие Typst в блокер для самой структуры документа

## Design Boundaries

- не добавляй водяные знаки и “сгенерировано ИИ”
- не меняй смысл исходного артефакта
- не добавляй маркетинговые украшения без запроса
- если текст неполный и содержит критические `[уточнить]`, сначала спроси недостающие данные

## Handoff

После оформления обнови `база/индекс.md`:

- исходный файл
- созданный `.typ`, если есть
- созданный `.pdf`, если есть
- что осталось доделать
